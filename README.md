Stálá adresa Voxcutu (https://jachben.github.io/voxcut/).
Voxcut běží na Macu přes tunel, jehož adresa se mění. Server na Macu sem při každé změně zapíše aktuální adresu (adresa.json)
a tahle stránka na ni přesměruje. Nic dalšího tu není – žádné účty ani klíče.

Prodejní web (ceník, obchodní podmínky, kontakt) je ve složce web/ → https://jachben.github.io/voxcut/web/ .
Vzniká skriptem `VoxSub Pro/web-na-github.py` z webu na Macu, ručně ho neupravuj.
